# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities in public GitHub issues.
Send details privately to **support@yivpn.net** with subject `[SECURITY] YIVPN Report`.
We acknowledge reports within 48 hours.

## Package Verification

Every official YIVPN binary published on `yivpn.net` and `github.com/yivpn-official/yivpn/releases` is accompanied by a verifiable SHA-256 digest in [`manifest/releases-v1.0.4.json`](./manifest/releases-v1.0.4.json).
